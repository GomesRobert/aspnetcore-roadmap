O C# é uma linguagem de programação criada pela Microsoft Fortemente tipada, compilada, gerenciada e orientada a objetos. Somente grandes empresa utilizam ela, muito boa para desenvolvimente web e para jogs tbm 

funciona através do .NET e do CLR (Common Language Runtime). O código escrito em C# é convertido para uma linguagem intermediária chamada IL (Intermediate Language) e, durante a execução, o CLR transforma esse IL em código de máquina através do JIT (Just In Time).


Resumindo o fluxo:
C# → IL → CLR/JIT → Código de máquina → execução
